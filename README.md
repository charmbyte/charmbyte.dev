# CharmByte

Marketing site for [CharmByte, LLC](https://www.charmbyte.dev) — Vite, React, TypeScript, Tailwind CSS v4, and shadcn/ui. Uses **pnpm**.

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```

## Replace logos

Drop your final assets over these placeholders:

- `public/brand/logo.svg`
- `public/brand/pwtycoon-logo-outline.svg`
- `public/favicon.svg`

## Add a game

Edit `src/data/games.ts` and add an entry with `name`, `href`, `logo`, and `description`.
